# ocr-compare — 文字起こしエンジンの比較

作成日時: 2026-09-21 20:30
更新日時: 2026-09-21 20:30

同じページ画像を複数のエンジンで文字起こしし、手で作った正解テキストとの文字誤り率(CER)と
1 ページあたりの時間を比べる。使い方は [compare.py](compare.py) の先頭を参照。

作業フォルダは `data/ocr-compare/`(git 管理外)。本の本文を含むため、正解テキストや
出力はリポジトリに入れない。

## エンジン

| 名前 | 中身 | 準備 |
| --- | --- | --- |
| `bookviewer` | アプリ本体の変換(YomiToku + 段落の分け直し・キャプション判定) | backend の venv |
| `yomitoku` | YomiToku の Markdown 出力そのまま | backend の venv |
| `ndlocr` | NDLOCR-Lite(国立国会図書館) | `vendor/ndlocr-lite` に clone し、その中に venv |
| `vlm` | Vision LLM(llama-server) | GGUF + mmproj |

## 結果(2026-09-21)

縦書き 4 ページ(土と生命の46億年史・三つの石で地球がわかる)と横書き 2 ページ(気象学入門)。
正解は本文と見出しだけ(図のキャプションを含めない)なので、キャプションを出すエンジンは
その分が「余分」として数えられる。

| エンジン | CER | 誤字 | 欠落 | 余分 | 1 ページ |
| --- | --- | --- | --- | --- | --- |
| bookviewer(採用) | 2.6% | — | — | — | 0.7 秒 |
| YomiToku そのまま | 2.8% | 0.23% | 0.22% | 2.35% | 0.6 秒 |
| NDLOCR-Lite | 4.4% | 0.39% | 0.80% | 3.18% | 0.9 秒(CPU) |
| Qwen3.8-27B(Q4_K_M) | 5.9% | 0.39% | 1.55% | 3.94% | 17.5 秒 |

- VLM は「一様→一律」「起こって→起きて」「でできた→できた」のような、もっともらしい書き換えと
  脱落が出る。読んでも気づきにくい。
- NDLOCR-Lite は縦中横の数字や「℃」を落としやすい(「30～35」→「～ ～」)。
- YomiToku はルビを本文に混ぜる(`ignore_ruby` で除ける)。節見出しの飾り枠を図として検出する
  ことがあり、アプリ側で横長の帯は見出しとして扱っている。
