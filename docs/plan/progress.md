## 注意点

- `content.json` は生成物(消してもよい。次に本を開いたとき・チャットや索引で本文を使うときに作り直す)。
  本文の手修正・文字起こし・章立ての保存のあとは、指紋が変わるので自動で作り直される。
- テキスト表示の読書位置は「画面の本文が原本のどのページまで進んだか」。再開すると、そのページから
  始まる最初のブロックのある画面に戻る(同じ画面か、少し手前)。

- 本フォルダ方式より前の作品(ルート配下の zip を直接登録したもの)は DB に残っていれば
  読めるが、スキャンでは登録されない。その zip は「未取り込み」として案内に出る。
  取り込むと同じ ID で本フォルダの作品に置き換わり、読書位置・しおりは引き継がれる。
- 本フォルダが消えた作品はスキャン時に索引から外れ、読書位置・しおりも消える。
- 取り込みダイアログは既存部品(`.modal` / `.seg` / `.btn`)と既存の値で組んだ。エラー色は
  スタイルガイドの `#ff8a8a` を `--danger` トークンとして `:root` に追加して使っている。
- 比較の正解テキスト・出力は `data/ocr-compare/`(git 管理外。本の本文を含むため)。
- NDLOCR-Lite の比較用 clone と venv は `vendor/ndlocr-lite/`(git 管理外)。アプリ本体では使っていない。
- YomiToku のモデルは CC BY-NC-SA 4.0(非商用)。個人利用の前提。
- 既存の library.db に残る `analysis` / `page_analysis`(漫画の解析結果)は使っていないが消していない。
- ルビ混入の修正、図の中の文字を残す変更より前に文字起こししたページは、やり直すと反映される。
  章立ての精度に関わるので、章立ての前に全ページをやり直すのがよい。
- 「要確認」は確信度の記録を始めてから文字起こししたページだけに付く(古いページはやり直すと付く)。
- 既存のページにはルビが無い(やり直すと付く)。ルビを含む行は「要確認」の一覧に出ない(行の文字列が
  本文にそのまま無いため)。
- ページ間のつなぎの字下げ判定(`head_continues`)も、記録を始める前のページには無い(本文だけで判断する)。
  やり直すと、章の書き出しなど字下げで始まるページを誤ってつながなくなる。
- 本文検索の索引の `page_end` は、レビュー修正より前に作った索引には無い(NULL = ページ内で完結の扱い)。
  「索引を作る」で作り直すと付く。
- `search_meta` の指紋はファイルの更新時刻を使うので、本フォルダをコピーして戻した場合などは 1 回だけ全冊読み直す。
