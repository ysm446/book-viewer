## 2026-10-26

- テキスト表示にハイライトを追加した。
  - 本文を選ぶと小さなメニューが出て、色(黄 / 緑 / 桃)を付けたり、メモを添えたりできる。付けたハイライトをクリックすると、
    色の変更・メモの編集・削除ができる(メモのあるハイライトには点線の下線が付く)。段落をまたいで選んでもよい。
  - リーダー上部の「ハイライト」で一覧を開ける。本の中の順に、色・抜粋・メモ・ページを並べ、クリックでその場所へ移る
    (画像表示ではそのページへ)。
  - 保存先は本フォルダの `highlights.json`。文字起こしをやり直したり本文を手直ししたりしても、選んだ文字列と前後の文字列から
    場所を探し直す。見つからないときは一覧に「位置ずれ」と出る。
  - 英語の本では原文に付ける(訳文だけを出している段落と訳文の部分には付けない)。
- しおりの保存先を、管理ルートの `library.db` から本フォルダの `bookmarks.json` に変えた。本フォルダだけでしおりも残り、
  索引を作り直したり本フォルダを移したりしても消えない。今までのしおりは、その本を開いたときに自動で移る。

## 2026-10-24

- 音声読み上げを追加した(ローカルの音声モデル Irodori-TTS。日本語専用)。
  - テキスト表示のツールバーの「読み上げ」で今の画面の先頭から、段落の右クリックの「ここから読み上げる」でその段落から読む。
    読んでいる段落をハイライトし、画面の終わりまで読むと自動でページを送る。一時停止 / 再開 / 停止、速さ(0.8〜2.0)。

    読み上げのときに自動で起動する(初回はモデル約 3.4 GB の取得で数分かかる)。別のアプリで入れたサーバーのフォルダや、
    起動済みのサーバーの URL も指せる。モデルは `D:\ai-models\tts\hf-cache`(無ければ Hugging Face の既定のキャッシュ)。
  - 読み上げの音声(blob)を画面の CSP(`media-src`)で許可した(「音声を再生できません」の修正)。
  - 声は「声の説明」(キャプション)・参照音声(wav)・seed で変えられる。合成した音声は `data/tts-cache/` に置き、
    同じ本文・同じ声は合成し直さない。

## 2026-10-23

- 本文の中を探せる検索結果の画面を追加した(Google の検索結果のように、一致した段落を抜き出して並べる)。
  一覧の検索欄で Enter(または「本文の中の箇所を見る」)、どこからでも Ctrl+F で開く。本ごとに上位 3 件と件数を出し、
  「すべて表示」でその本の全件をページ順に見られる。空白で区切るとすべての語を含む段落を探す。結果をクリックすると
  その本のその段落へ移り、テキスト表示では探した語をハイライトする。今の読書位置より先の箇所には「未読」と出す。
  本を開いているときは「この本」だけに絞れる。初回の起動時に、全冊の検索の索引を作り直す。
  英語の本の箇所には、訳してあれば一致した文の日本語訳を添える(自然な訳を優先。「訳を併記」で消せる)。
  英語の本は訳文も検索の対象にしたので、日本語の語(例: 「リンゴ」)でも訳してある段落が見つかる(原文の文も添える)。
  語が一致しなくても意味の近い段落も探す(例: 「雲ができる仕組み」「象を連れてアルプスを越えた」)。意味だけで
  見つかった箇所には「意味が近い」と出る。英語の本も原文のまま日本語の文で探せる。そのための段落の索引は、文字起こしの
  あとと起動時に、キューで自動で作る(ステータスバーの「意味の索引」。全 7 冊で 40 秒ほど。本文が変わらない段落は作り直さない)。
  検索中は結果の一覧の先頭に「検索中…」とスピナーを出し、前の結果を薄くする(最初の検索はモデルの読み込みで 10 秒ほどかかる)。
- 英語の本で、今の画面の段落だけ・1 段落だけを訳せるようにした(訳文を出しているとき)。テキスト表示のツールバーの
  「この画面を訳す」と、段落の右クリックの「この段落を訳す」。訳した段落は訳し直しになる。まだ何も訳していない本でも、
  読んでいるところから少しずつ訳せる。「訳し直す」のメニューは、全部と、指示を書き直す前の段落の訳し直しにした。
- 英語の本の訳の種類を選べるようにした。組み込みの「自然な訳」「直訳」に加え、訳し方の指示を書いて自分の種類
  (例: 村上春樹風)を作れる(「表示」の「訳・辞書」→「訳の種類」→「種類を作る・編集する…」)。訳は種類ごとに保存し、
  人名などの訳語は種類をまたいでそろえる。指示を書き直したら、前の指示で訳した段落を「訳し直す」から訳し直せる。
  これまでの訳は「自然な訳」として引き継ぐ。
- 「表示」のバーを「本」「文字」「訳・辞書」のタブに分け、選んだタブの項目だけを出すようにした(項目が増えて
  1 列に並んでいたため)。最後に開いたタブを覚える。ラベルも短くした(本の言語 → 言語、本文の組み方 → 組み方、
  文字サイズ → サイズ)。
- テキスト表示の文字の太さを選べるようにした(「表示」の「文字の太さ」)。書体ごとに用意されている太さを、書体での
  呼び名で選ぶ(ゴシックは Light / Semilight / Regular / Semibold / Bold、游明朝は Light / Regular / Demibold、
  BIZ UD明朝は Medium / Bold、Noto Serif JP は ExtraLight〜Black の 7 種類、しっぽり明朝は Regular のみ)。書体を変えて同じ太さが無いときは、いちばん近い太さにする。見出しは本文より一段太く表示する。
- 翻訳中の訳文を、LLM が書いている途中から少しずつ表示するようにした(ストリーミング)。以前は約 10 段落の訳が
  できあがるまで待ち、さらに 10 秒おきにしか画面を更新していなかった。
- 英語の本の日本語訳を訳し直せるようにした。テキスト表示のツールバーの「訳し直す」から、今の画面の段落だけ、
  または全部を、今読み込んでいるモデルで訳し直す(人名などの訳語はそのまま使う。新しい訳が取れなかった段落は前の訳を残す)。
  どのモデルで訳したかを段落ごとに記録し、「訳 N / M」にマウスを乗せると表示する。
- 辞書のポップアップを Escape で閉じると、リーダーまで閉じて一覧に戻ってしまっていたのを直した。
- セピアテーマで灰色のまま残っていた部分を、セピアの色にした: テキスト表示の区切り線、セレクトを開いたときの
  選択肢、入力欄の案内文(チャットの「モデルを読み込むと質問できます」など)、設定のスライダー、スクロールバーの角、
  文字を選んだときの色(ウィンドウが前面にないとき)、
  画像表示のスクラバーの暗い帯としおりのバッジ(セピアでは焦げ茶)。黒・白テーマでも区切り線などは配色に合わせた。
- 英語の本の日本語訳と対訳表示を追加した。「表示」の「日本語訳」で 原文 / 訳文 / 対訳 を切り替え、テキスト表示の
  「残り N 段落を翻訳」でローカル LLM が段落ごとに訳す(訳しながら読める。止めても続きから)。対訳は 文 / 段落 / 節 の
  単位で並べられ、単位を変えても訳し直さない。人名などの訳語は本ごとにそろえる。
- 翻訳中の進み具合の横に経過時間を表示するようにした(1 時間を超えると 時:分:秒)。
- 英語の本で、本文の単語にマウスを乗せると英和辞書の意味を出すようにした(「表示」の「辞書」でオン / オフ)。
  frightened → frighten のように、語尾の変わった形は元の形でも引く。辞書は EJDict(パブリックドメイン)で、
  初めて引いたときに自動で取得する。意味を出している間は、その単語をハイライトする。
- 英語の本の文字起こしで、引用符の付いた章の頭文字(“OH, LOOK!” など)と、番号付きの箇条を正しく扱うようにした。

- 洋書(英語の本)を取り込めるようにした。取り込みダイアログと「表示」で本の言語(日本語 / 英語)を選ぶ
  (取り込み時の初期値は書名から推測)。英語の本は文字起こしで、折り返しの行を空白でつなぎ、行末のハイフンで切れた語
  (ページをまたぐものも)をつなぐ。章の始まりの大きな頭文字を本文の頭に戻し、場面転換の飾り(* * *)を区切り線にし、
  箇条書きの点をリストにする。Vision LLM で文字起こしするときも英語用の指示で読む。日本語の本の文字起こしは変わらない。

- 保存の通知に保存先のフルパスを出すようにした。

- 画面が取れなかった(空の画像が返った)ときは、空のファイルを作らずエラーとして知らせる。
