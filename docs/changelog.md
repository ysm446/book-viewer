# Changelog

## 2026-09-22

- 漫画向けの解析(ページ説明・あらすじとタグの生成)をアプリから削除した。設定ファイルに残っていた解析用の項目は、次に設定を保存したときに消える。
- 一覧の検索が、書名・著者・章の要約・文字起こしした本文から探すようになった。
- 同じ本でも種類の違う処理(文字起こしと検索の索引づくりなど)は、続けて順番待ちに入れられるようにした。
- 画面の「作品」という表記を「本」にした。
- 起動直後に、接続先が決まる前のバックエンドへ問い合わせてエラーを出していたのを直した。
- チャットに本文検索を追加。チャット欄の「索引を作る」で本文の検索用の索引を作ると、今のページから遠い箇所でも、読んだ範囲から質問に関係する本文を探して答えに使う(埋め込みモデルが必要。例: Qwen3-Embedding-4B)。
- 埋め込みモデルを会話用のモデル一覧に出さないようにした。
- テキスト表示にページごとの「編集」を追加。原本の画像と見比べながら本文を直せる。読み取りに自信がない行は「要確認」として表示し、クリックで選択できる。手で直したページは「全ページやり直す」で上書きしない。

## 2026-09-21

- 目次パネルに「編集」を追加。章・節の種類・名前・開始ページを直したり、追加・削除したりできる。範囲が変わった章の要約だけが消える。
- テキスト表示に「全ページやり直す」を追加(文字起こしの改良を既存の本に反映するため)。
- 章立てと要約を追加。リーダーの「目次」から、文字起こしした本文をもとに LLM が章立て(章と節)を作り、章ごと・本全体の要約を作る。章・節をクリックするとそのページへ移動する。
- チャットの文脈に、読み終えた章の要約を加えた(先の章の要約は使わない)。
- 文字起こしで、キャプションの無い図(章の扉・目次など)は図の中の文字を残すようにした。
- 漫画向けの「解析」パネル・メニュー・設定を画面から外した。設定のタブ「AI 解析」は「文字起こし」になった。
- チャットを本向けに変更。いま開いているページまでの本文(文字起こし済み)をもとに答え、根拠のページを添える。先のページは読まない。システムプロンプト・質問候補・表示の文言も本向けにした(以前の漫画向けの既定プロンプトのままなら自動で置き換わる)。
- 文字起こしで、ルビだけが本文の段落として混ざることがあったのを修正。
- 文字起こしの既定エンジンを YomiToku(日本語の文書 OCR)に変更。Vision LLM より字の読み違い・抜けが少なく、1 ページ 1 秒未満で動き、モデルの読み込みも不要。設定 > AI 解析 で Vision LLM に戻せる。
- 文字起こしで図・表を切り抜き、テキスト表示の本文中にキャプション付きで表示するようにした(本フォルダの `figures/` に保存)。
- 漫画向けのページ OCR(mokuro / manga-ocr)を削除。
- リーダーに「画像 / テキスト」の表示切り替えを追加。テキスト表示では、ページを Vision LLM で文字起こしした本文（Markdown）を読める。縦書きの本は縦書きで表示する。
- 文字起こし機能を追加。テキスト表示のツールバー、または一覧のメニュー「文字起こしする」から、未処理のページを解析キューで順に処理する。本文は本フォルダの `pages/0001.md` … に保存される。表示中のページだけやり直すこともできる。
- リーダーの「表示」に書字方向（横書き / 縦書き）の切り替えを追加。取り込み後でも変更できる。
- 本の取り込み機能を追加。一覧上部の `＋` またはウィンドウへのドラッグ&ドロップで zip / cbz / pdf を選び、書名・著者・書字方向（横書き / 縦書き）を確認して取り込む。元ファイルはコピーして残すか移動するかを選べる。
- 取り込んだ本は管理ルート直下に 1 冊 1 フォルダ（`book.json` + `source/`）で保存するようにした。一覧は本フォルダから作る。
- 管理ルート内に未取り込みの zip などがあると、一覧上部に案内を出してまとめて取り込めるようにした。
- 本のメニューの「ファイル名を変更」を「名前を変更」にし、本フォルダ名も追従するようにした。削除は本フォルダごとごみ箱へ移動する。
- アプリ名を「Manga Viewer」から「Book Viewer」に変更（ウィンドウタイトル・パッケージ名など）。
- 管理ルートのデータフォルダを `.manga-viewer/` から `.book-viewer/` に変更。既存の `.manga-viewer/` は初回アクセス時に自動でリネームされる。
