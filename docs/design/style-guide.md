# UI スタイルガイド

作成日時: 2026-08-11 18:52
更新日時: 2026-09-21 21:40

このアプリ（book-viewer。旧 manga-viewer）の UI を一貫させるための唯一の基準。色・タイポグラフィ・余白・
部品・状態表現・モーションをここに集約する。**UI を変更するときは必ずこの文書に従う。**

- 旧 `docs/rules/electron-design-rules.md`（Electron 全般のデザインルール）は本書に統合し、
  実装で使っている実際の値（[../../src/renderer/src/styles.css](../../src/renderer/src/styles.css)）に合わせて具体化した。
- 本書と実装が食い違っている場合は、まずどちらが正しいかを判断し、
  「本書を直す」か「実装を直す」かを決めてから作業する。黙って両方を放置しない。
- ここに書かれていない新しいパターンを作ったときは、実装と同時に本書へ追記する。

---

## 0. 大原則

このアプリは「長時間、静かな部屋で本を読む / 蔵書を整理する」ためのデスクトップアプリ。
そのため次を優先する。

1. **ページ（画像 / 本文）が主役。** UI はページの邪魔をしない。リーダー周辺は暗く沈め、装飾を足さない。
2. **情報密度と視認性。** 余白を広く取るより、alignment とグルーピングで読みやすくする。
   ランディングページ的な広い余白は使わない。
3. **落ち着いたダークテーマ一本。** ライトテーマは持たない（`color-scheme: dark`）。
   真っ黒背景・真っ白文字は避け、明度を寄せて目の負担を減らす。
4. **OS ネイティブに近い控えめな質感。** 強いグラデーション、大きな影、過度な角丸、
   派手なアニメーションは使わない。
5. **状態が常に分かる。** hover / active(選択) / focus / disabled / loading / empty / error を
   必ず設計する。色だけで状態を伝えない。
6. **操作領域は見た目より広く。** ドラッグ・リサイズ・スクラバーなどは hit area を広げる。

## 1. 色

### 1.1 トークン

色は必ず `:root` のカスタムプロパティを使う。**新しい hex 値を各所に直書きしない。**
新しい色が要るときは、まずトークンで表現できないかを検討し、どうしても必要なら
`:root` にトークンを足してから使う。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#1c1c1d` | アプリの地。ウィンドウ全体の背景 |
| `--panel` | `#242425` | トップバー / ステータスバー / 左ペイン / モーダル本体 |
| `--panel-2` | `#2c2c2e` | 通常ボタン、ポップアップ、バッジ、行 hover、トースト |
| `--panel-3` | `#353538` | もう一段上げる面。hover の上、選択（トグル ON）、押し込み表現 |
| `--panel-head` | `#202021` | モーダルのヘッダ帯（本体より一段沈める） |
| `--input-bg` | `#1d1d1e` | 入力欄・セレクト・ルート表示枠の背景（地より沈める） |
| `--border` | `#313134` | 基本の境界線。区切りは強い線ではなく背景差 + 薄い border で作る |
| `--text` | `#d4d4d8` | 本文・主要ラベル |
| `--text-sub` | `#a1a1a6` | 補助テキスト、メタ情報、非選択のナビ項目 |
| `--text-dim` | `#727277` | さらに弱い説明文、caret、disabled 相当の文字 |
| `--accent` | `#4c8de5` | アクセント（青）。用途は 1.3 を厳守 |
| `--accent-soft` | `rgba(76,141,229,.14)` | 一覧の選択行など、accent の淡い面 |
| `--danger` | `#ff8a8a` | エラー / 危険の文字色（1.2 の意味色をトークン化したもの。新規コードはこれを使う） |
| `--warn` | `#e5b04c` | 注意（リソースメーターの 65% 超など）。通常時のメーターは `--text-sub` の灰色 |

面の階層は `--bg` → `--panel` → `--panel-2` → `--panel-3` の順に明るくなる。
hover で 1 段上げ、選択・押し込みで 2 段目（`--panel-3`）まで、が基本。

**リーダーの舞台だけは例外で `#151516`**（`.viewer` / `.reader`）。ページ画像を浮かせるため、
アプリの地よりさらに暗く落とす。この 2 箇所以外でこの値を使わない。

### 1.2 意味色（セマンティック）

| 用途 | 色 | 使う場所 |
| --- | --- | --- |
| 成功 / 正常 | `#7bd88f` | バックエンド ready、LLM ping OK |
| エラー / 危険（文字） | `#ff8a8a` | エラー文言、削除メニュー項目の文字色 |
| 危険（塗り） | `#c0392b` | 削除ボタンの hover 背景（× / ごみ箱など） |
| エラー枠 | `#7f3a3a` | エラートーストの border |

危険操作は色だけに頼らない。確認ダイアログ、文言、配置（メニュー末尾 + セパレータ）で区別する。

### 1.3 青（accent）の使いどころ ← 重要

青は「今アプリが動いている / これが主役」を示す色。**染めすぎない。**

**青を使ってよい:**

- モデルの状態表示（ロード中のグロー、ロード済みバッジ、モデル名の強調）
- 主アクションのボタン（`.btn-primary`。ダイアログの確定、送信など画面に 1 つ）
- チェックボックス / トグルスイッチの ON
- セグメントコントロールの選択中（`.seg-active`）
- 入力欄の focus border、focus-visible の outline
- 一覧の選択行（`--accent-soft` の淡い面）、ドロップ位置インジケータ
- ごく短い注意喚起の文字（トーストのヒント、動的サジェストの印）

**青を使わない:**

- 汎用ボタンのトグル ON / 押し込み状態 → `--panel-3` + 明るめ border（`.btn-active`）
- チャットのユーザー発言の吹き出し → `--panel-3`
- リスト行の hover → `--panel-2`
- 単なる見出し・アイコン・区切り

> 選択やトグル ON は原則グレー、青はモデル状態・主アクション・チェック ON に限定する。

## 2. タイポグラフィ

### 2.1 フォント

UI は system font stack。日本語込みで次を使う（`body` に定義済み。個別に指定しない）。

```css
font-family:
  system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Yu Gothic UI',
  'Hiragino Sans', 'Noto Sans JP', sans-serif;
```

モデル名・パス・ログ・ID など「機械の文字列」は monospace。

```css
font-family: ui-monospace, 'Cascadia Mono', 'Consolas', monospace;
```

数値が並んで更新される箇所（リソース使用率、サイズ、経過時間）は
`font-variant-numeric: tabular-nums;` を付けて桁を揺らさない。

### 2.2 サイズ階層

`body` の既定は `13px` / `line-height: 1.4`。ここから外れるときだけ指定する。

| サイズ | 用途 |
| --- | --- |
| `18px` / `20px` | リーダーの大きいアイコンボタンなど、ごく一部の強調 |
| `16px` | モーダルのタイトル、アイコンボタンのグリフ |
| `14px` | トップバーのタイトル、作品タイトル、モデル名 |
| `13px` | **既定。** 本文、ボタン、入力欄、一覧タイトル、チャット本文 |
| `12px` | 補助ラベル、メタ情報、セグメント、チップ、バッジ、説明文、ポップアップ項目 |
| `11px` | 最小限の補足（トーストのファイル名、キャプション） |
| `10px` | ステータスバーの計器ラベルや caret などの記号のみ |

`10px` / `11px` は「読ませる文章」に使わない。読ませる文章の下限は `12px`。

**例外: リーダーのテキスト表示（`.book-md`）。** 本文を長く読ませるため UI の階層とは別に組む。

| 要素 | サイズ / 行間 |
| --- | --- |
| 本文 | `16px` / `line-height: 1.9`、1 行は最大 `42em`（`max-inline-size`） |
| 見出し | `#` = `20px`、`##` = `18px`、`###` 以下 = `16px`（いずれも `600`、行間 `1.5`） |
| 表・インラインコード | `14px` |
| ルビ（`rt`） | `10px` / `--text-sub`（本文 16px の約半分。ルビに限り 10px を文字に使う） |
| ページ番号ラベル | `11px` / `--text-dim` |

縦書きの本は `writing-mode: vertical-rl` で組み、余白・幅は論理プロパティ
（`margin-inline` / `padding-block` など）で書いて横書きと共通にする。

### 2.3 行間

- UI ラベル・一覧項目: `1.4`（既定）
- チャット本文・あらすじなど読ませる文章: `1.55`
- 説明文（`settings-desc` など）: `1.5`
- ボタン内やツールバーの 1 行テキストは固定高 + 中央揃えで扱い、行間で調整しない

### 2.4 その他

- 見出しの階層を増やさない。設定のセクション見出しは
  `12px` / `font-weight: 600` / `letter-spacing: .06em` / `--text-sub` の小見出しスタイルに揃える。
- 長いタイトル・パスは 1 行省略（`overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`）を
  基本にし、全文は tooltip か詳細ペインで見せる。UI を押し広げさせない。
- UI 全体は `user-select: none`。ユーザーがコピーしたい本文（チャット応答、あらすじ、
  抽出テキスト）だけ選択可能にする。

## 3. 余白とサイズ

### 3.1 グリッド

基本単位は **2px 刻み、実質 4px グリッド**。使う値は `2 / 4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24`。
奇数や `5px` / `7px` のような値を新しく増やさない（`5px 10px` のような既存例はそのまま）。

| 場面 | gap / padding |
| --- | --- |
| 高密度なツールバー、行内の要素間 | `gap: 4px` 〜 `8px` |
| 関連するまとまり（フィルタ列、チップ列） | `gap: 6px` 〜 `12px` |
| ステータスバーの計器どうし | `gap: 14px` |
| 設定行の左右（ラベルとコントロール） | `gap: 24px` |
| パネル内の余白 | `padding: 8px 10px` 〜 `12px 20px` |
| モーダルのヘッダ | `padding: 12px 16px`（小） / `12px 20px`（大） |

### 3.2 コントロールの高さ

| 高さ | 用途 |
| --- | --- |
| `30px` | **標準。** ボタン（`.btn`）、アイコンボタン（`.icon-btn`）、入力欄、検索欄 |
| `28px` | 少し詰めたい場所（フィルタのセレクト） |
| `26px` | 補助的な小コントロール（タグ入力、タグ生成ボタン）、ステータスバーの高さ |
| `24px` | 行内に埋め込む極小ボタン（三点メニュー）。これがクリック領域の下限 |
| `20px` | ステータスバー内のトグル（バー高 26px の中に収める） |

クリック可能な領域は最低 `24px`。頻繁に押す操作は `28px` 以上を確保する。

### 3.3 主要レイアウト

- 縦構造は `topbar`（`padding: 6px 14px`）→ `split`（左ペイン + divider + ビューワ）→
  `statusbar`（`height: 26px`）。
- 左ペイン（explorer）と右ペインは可変。分割は `.divider` で行い、最小幅を必ず決める。
- スクロールする領域は `min-height: 0` / `min-width: 0` を付けて flex の潰れを防ぐ。

## 4. 角丸・境界・影

### 4.1 角丸

| 値 | 用途 |
| --- | --- |
| `6px` | **標準。** ボタン、入力欄、リスト行、ポップアップ、セグメント、トースト |
| `4px` | 小さい要素（極小ボタン、バッジ、メニュー項目、ステータスピル） |
| `8px` | モーダル、大きめのカード |
| `3px` | チェックボックスなど極小の面 |
| `999px` / `50%` | プログレスのトラック / 円形のつまみ・削除ボタン |

吹き出しは `10px` + 発言者側の角だけ `3px`、チップは `12px` 〜 `14px`（丸みのある小片）。
これ以外の中途半端な角丸を増やさない。

### 4.2 境界

- 区切りは `1px solid var(--border)` と背景差の組み合わせ。太い線は使わない。
- パネル間の区切りは影ではなく border / background で行う。
- 選択中の枠を強調したいときは border の色を上げる（`#55565c` 程度）か accent を使う。

### 4.3 影

影は「浮いている要素」だけに使う。常時表示のパネルやカードには付けない。

| レベル | 値 | 用途 |
| --- | --- | --- |
| ポップアップ / メニュー | `0 8px 24px rgba(0,0,0,.45)` | 行メニュー、モデル一覧 |
| トースト | `0 8px 28px rgba(0,0,0,.45)` | 右下トースト |
| モーダル | `0 12px 40px rgba(0,0,0,.5)` | 設定・リネームなど |

モーダルの backdrop は `rgba(0,0,0,.5)`。

## 5. 部品カタログ

新しい UI を作るときは、まずここにある部品で組めないかを確認する。
似た用途の部品を新規に作らない。

### 5.1 ボタン

| クラス | 見た目 | 使う場面 |
| --- | --- | --- |
| `.btn` | `height 30px` / `padding 0 12px` / `--panel-2` / border / `radius 6px` | 標準のテキストボタン |
| `.btn-primary` | `--accent` 塗り + 白文字 | 画面内で 1 つだけの主アクション |
| `.btn-active` | `--panel-3` + 明るい border | トグル ON / 押し込み（**青にしない**） |
| `.icon-btn` | `30x30` / 透明 / `font-size 16px` | アイコン単体。hover で `--panel-2` + border |
| `.icon-btn-lg` | `font-size 20px` | リーダーなど大きく押したい所 |

- hover は `:hover:not(:disabled)` で書く。disabled に hover 効果を出さない。
- disabled は `opacity: .5` + `cursor: default`。
- アイコン単体ボタンには必ず `title`（tooltip）か `aria-label` を付ける。
- 危険操作のボタンは hover で `#c0392b` 塗り + 白文字にする。

### 5.2 セグメントコントロール（`.seg` / `.seg-btn`）

同じ設定軸の切り替え（表示方向、綴じ方向など）に使う。画面の切り替えには使わない。
枠を 1 つ持ち、内側は `border-left` で区切る。選択中（`.seg-active`）は `--accent` 塗り + 白文字。

### 5.3 トグルスイッチ（`.switch`）

ON / OFF の設定に使う。`38x22`、つまみ `16px`、ON で `--accent`。
`transition` は `.15s`。「即時に効く設定」に使い、確定ボタンが要る設定には使わない。

### 5.4 チェックボックス

ネイティブ矩形は使わず `appearance: none` のフラットな `15x15` / `radius 3px`。
ON は `--accent` 塗り + 白のチェック。複数選択・任意項目に使う。

### 5.5 入力欄

- 1 行入力: `height 30px` / `padding 0 8px` / `--input-bg` / border / `radius 6px` / `13px`。
- 小さい入力（タグなど）は `height 26px` / `12px`。
- focus は `outline: none` にした上で **必ず** `border-color: var(--accent)` を付ける。
  focus の手掛かりを消さない。
- textarea は本文フォント + 行間を優先し、最大高とスクロール挙動を決めてレイアウトジャンプを防ぐ。
- placeholder は薄くしすぎない（`--text-dim` 相当まで）。

### 5.6 セレクト

`--input-bg` + border + `radius 6px`。高さは `28px` 〜 `30px`。
選択肢が多い / 説明が要る場合は select ではなくポップアップメニューにする。

### 5.7 チップ

| クラス | 用途 |
| --- | --- |
| `.tag-chip` | 付与済みタグ。`radius 12px` / `12px` / 右端に円形の削除ボタン |
| `.chat-chip` | 質問テンプレート。`radius 14px` / 押せるボタン |

動的に生成された候補は border を `--accent` にして固定候補と区別する（塗りは変えない）。

### 5.8 バッジ

`.mp-badge` 系。`12px` / `padding 2px 8px` / `radius 4px` / `--panel-2` + border。
状態を表す場合だけ文字色と border 色を変える（ロード済み = accent）。

### 5.9 リスト行

- 行は `radius 6px`、hover で `--panel-2`、選択で `--accent-soft`。
- 行内の操作ボタンは通常 `opacity: 0` で隠し、`行:hover` / `.is-open` / `:focus-visible` で出す。
  **キーボード操作で到達できるよう `:focus-visible` を必ず含める。**
- 重要な操作は隠さず常時見せる。
- 並び替えのドロップ位置は `box-shadow: 0 ±2px 0 var(--accent)` の線で示す。
- タイトルは 1 行省略。サムネイル + タイトル + メタ情報の優先度を崩さない。

### 5.10 ポップアップメニュー

`--panel-2` + border + `radius 6px` + 影、`padding 4px`、`min-width 180px`。
項目は `padding 7px 10px` / `12px` / `radius 4px`、hover で `--panel-3`。
区切りは `border-top: 1px solid var(--border)` + `margin: 4px 0`。
破壊的な項目は末尾に置き、`#ff8a8a` の文字色にする。
背後には `.popup-backdrop`（`position: fixed; inset: 0`）を敷いて外側クリックで閉じる。

### 5.11 モーダル

- 構造: `.modal-backdrop`（`rgba(0,0,0,.5)`, `z-index: 50`）→ `.modal`（`--panel` / `radius 8px` /
  `max-height: 85vh` / 影）。
- ヘッダは `--panel-head` + 下 border。タイトルは `16px`。
- 幅は内容に合わせる。確認・入力系は `440px`、設定のような多面 UI は `720px`、
  いずれも `max-width: 92vw`。
- 使うのは破壊的操作・重要設定・複雑な選択のときだけ。軽い選択はポップアップにする。
- Escape で閉じる。外側クリック・Enter の扱いを画面ごとに決めて統一する。
- close / cancel / confirm の位置を全モーダルで揃える（確定は右）。

### 5.12 トースト

右下固定（`right: 16px` / `bottom: 36px` = ステータスバーの上）、`max-width: 380px`、
`--panel-2` + border + 影、`radius 6px`。本文 `12px`、補足 `11px`。
出現は `toast-in .16s ease-out`（下から 8px + フェード）。
エラー時は border を `#7f3a3a` に。閉じる × を必ず付ける。
**モーダルで止めるほどでない結果通知**（保存完了など）に使う。

### 5.13 プログレス / 計器

- 細いバー: トラック `height 3px` 〜 `6px`、`radius 999px`、背景 `rgba(255,255,255,.1)`。
  fill は `transition: width .3s ease`（計器は `.5s ease-out`）。
- 進捗の数値は `tabular-nums` で桁を固定する。
- 不定進捗はスピナー（`animation: spin .8s linear infinite`）。

### 5.13.1 取り込みダイアログ（`.import-modal`）

`720px` のモーダル。1 ファイル 1 行で、先頭にチェックボックス、右に書名 / 著者の入力欄
（`30px`）と書字方向のセグメント。フッタに元ファイルの扱い（コピー / 移動）のセグメントと、
キャンセル / 取り込む（主アクション）を置く。行の警告は `11px` / `--text-dim`、
失敗は `--danger`。

### 5.13.2 本文中の図（`.md-image`）と図の置き場所（`.md-figure`）

- `.md-image`: 切り抜いた図。中央寄せ、`max-block-size: 70vh`、`radius 4px`。キャプションは
  `figcaption`（`12px` / `--text-sub` / 行間 `1.5`）。縦書きの本でも図とキャプションは横書きで組む。
- `.md-figure`: 画像が無いとき（Vision LLM の文字起こし、表示を許可しない画像）の仮表示。
  `--panel-2` + border + `radius 6px`、`12px` / `--text-sub`。
- 画像は呼び出し側が許可したパス（本フォルダの `figures/`）だけを読み込む。LLM 出力の外部 URL は読まない。

### 5.13.3 目次パネル（`.toc-panel`）

リーダー上部の `.reader-info` パネルを使う（`max-height: 40vh`）。見出し行（`.reader-info-head`）は
`position: sticky` で上に残す。章の行は `radius 6px`、今読んでいる章は一覧の選択行と同じ
`--accent-soft`。章名は `13px` / `600`、節は `12px` / `--text-sub`、ページ範囲は `11px` / `--text-dim` /
`tabular-nums`。節は今読んでいる章だけ広げる。要約は `--panel-2` の面（`.toc-summary`）に `13px` / 行間 `1.55`。
先の内容を含む本全体の要約は `<details>` で畳んでおく。

編集モード（`.toc-edit`）は 1 項目 1 行: 種類のセレクト（`.filter-select`、`56px`）・名前の入力・開始ページ
（`72px`、`tabular-nums`）・削除（`24px` のアイコンボタン）。入力は `28px` / `13px` / focus で `--accent` の枠。
節の行は `24px` 字下げ。保存（主アクション）とキャンセルは右寄せ、追加は左。

### 5.13.4 本文の編集（`.text-edit`）

テキスト表示の本文エリアを左右に分ける。左は原本の画像（幅いっぱい、クリックで原寸 ⇔ 全体）、右は
上に見出し行（保存 = 主アクション、キャンセル）、要確認の行の一覧（`.text-edit-low-item`: `--panel-2` の
小さなボタン、`12px`、1 行省略）、残りを編集欄（`.text-edit-area`: `--input-bg`、`14px` / 行間 `1.7`、
focus で `--accent` の枠）。ページ番号の横の印（`.text-page-badge`）は `11px` の枠付きラベルで、色は付けない。

### 5.13.5 チャットの本文検索（`.chat-index`）

チャットのオプション行（`.reader-chat-opts`）の「本文を検索」は他の項目と同じチェックボックス。索引が無い・
古い・作成中のときだけ、その下に `.chat-index`（`12px` / `--text-sub` の説明 + `26px` の小さなボタン）を出す。

### 5.14 スクラバー / オーバーレイ

ページ上に重ねる UI は `rgba(0,0,0,.45)` 〜 `.6` の半透明パネルにし、
`transition: opacity .15s, transform .15s` でふわりと出す。
画像の上に不透明な面を大きく置かない。

### 5.15 リサイズハンドル（`.divider`）

見た目の線は `1px`（`::before`）、hit area は `width: 10px` / `margin: 0 -5px`。
`cursor: col-resize`。hover で線を `--accent` / `2px` に強調。
ドラッグ中はテキスト選択を抑制する。

### 5.16 スクロールバー

全体で統一（個別に上書きしない）。`width: 9px`、thumb `#3d3d40` / `radius 5px`、
hover で `#4e4e52`。track は描かず背景になじませる。

## 6. 状態表現

| 状態 | 表現 |
| --- | --- |
| hover | 面を 1 段明るく（`--panel-2` → `--panel-3`）。文字色だけの変化は補助的に |
| 選択 / ON | `--panel-3`（グレー）。一覧行は `--accent-soft`。青塗りは 1.3 の範囲だけ |
| focus | `outline: 1px solid var(--accent); outline-offset: 1px`（`:focus-visible`）。**消さない** |
| disabled | `opacity: .5` + `cursor: default` + hover 無効化。文字は `--text-dim` |
| loading | スピナー or グロー。ボタンは disabled にして二重実行を防ぐ |
| empty | 中央寄せの `--text-sub` / `--text-dim` の短い説明文。次の操作を示す |
| error | `#ff8a8a` の文言。原因と復帰手段を書く。黙って消えない |

---

## 7. モーション

- 目的は「変化に気付かせる」ことだけ。演出のためのアニメーションを足さない。
- 長さ: 状態変化 `.15s`、要素の出現 `.16s` 〜 `.22s`、進捗バー `.3s` 〜 `.5s`。
- イージング: `ease` / `ease-out`。バウンドや overshoot は使わない。
- ページ送りの演出（フェード / スライド）は `200ms` 前後に収め、連続操作を妨げない。
- 無限ループのアニメーションは「今動いている」ことを示す用途だけ（スピナー、モデルのグロー）。

---

## 8. アイコン

- 一般的に意味が通るものだけを使い、独自アイコンを増やさない。
- サイズは `16px` 基本、強調したい所だけ `18px` / `20px`。
- アイコン単体のボタンには `title` か `aria-label` を必ず付ける。
- 絵文字を装飾目的で本文に混ぜない（既存の ★ など機能を持つ記号は除く）。

---

## 9. アクセシビリティ

- キーボードだけで主要操作ができること。リーダーのページ送り、一覧の選択、
  モーダルの閉じるは特に確認する。
- `:focus-visible` のリングを消さない。hover で出す操作ボタンも focus で必ず現れること。
- 色だけで状態を伝えない（文字・アイコン・位置を併用）。
- disabled でも読める濃さを保つ。
- クリック領域は最低 `24px`、頻繁な操作は `28px` 以上。

---

## 10. 実装ルール

- スタイルは [../../src/renderer/src/styles.css](../../src/renderer/src/styles.css) に集約する。
  インライン `style` は「動的に計算する値」（幅の割合、座標、画像サイズ）だけに使い、
  色・角丸・余白などの静的な見た目をインラインで書かない。
- CSS フレームワーク（Tailwind 等）や CSS-in-JS を新規に持ち込まない。
- クラス名はケバブケース。機能ブロックの接頭辞を付けて衝突を避ける
  （`reader-` / `ex-` / `mp-` / `settings-` / `chat-` / `toast-` など）。
  状態は `is-` 接頭辞（`is-on` / `is-open` / `is-error` / `is-current`）。
- セクションコメント `/* ---- 名前 ---- */` で区切り、関連するクラスを近くにまとめる。
- 色・サイズは本書の表にある値から選ぶ。表にない値が必要になったら、
  本当に必要かを確認し、必要なら本書を先に更新する。
- 変更後は `npm run typecheck`、可能なら `npm run build` を実行する。

## 11. UI 変更時のチェックリスト

- [ ] 使った色はすべてトークン（または本書の意味色）か。新しい hex を直書きしていないか。
- [ ] 青（accent）を 1.3 の許可された用途以外に使っていないか。
- [ ] フォントサイズは階層表のどれかか。読ませる文章が `12px` を下回っていないか。
- [ ] 余白・高さ・角丸が既定値（4px グリッド / 30px / 6px）から外れていないか。
- [ ] hover / 選択 / focus / disabled / loading / empty / error を用意したか。
- [ ] `:focus-visible` のリングが残っているか。hover で出す操作が focus でも出るか。
- [ ] アイコン単体ボタンに tooltip / `aria-label` があるか。
- [ ] 長いテキストが省略され、UI を押し広げていないか。
- [ ] 既存の部品（5 章）で組めるものを新規に作っていないか。
- [ ] 危険操作に確認または取り消し手段があるか。
- [ ] 本書に無い新パターンを足したなら、本書と `docs/changelog.md` を更新したか。
